# Base Guide

This webpage is mostly about how to mod the game, but it might be helpful for people who want to set up a serious server or just want to mess around, but have in mind that both the clients and servers linked here are full of security holes and bugs. So if you host them publicly be aware of that.

First you should get a server up and running, for that do check [Server set-up](serverGuide.md)

As part of the process you will likely have downloaded a client. Regardless of which one you pick the modding process is very similar.
The differences will be just missing content like new gamemodes, features in the client or stuff like weapons and maps, but the modding process is the prety much the same in all clients.

Now lets get to the resources, it is recommended to use a Season 8 client since the newest client that has an open source server version available is compatible with that one, but you can use the S1 server and client if you prefer.

The last official client is S10, the difference between S8 and S10 is only has a bunch of feature most people don't care about, aside from new skins (which you can export back to S8 if you care enough) so it isn't 100% necessary unless you want those.



**There are other users making different tools for map viewing and other stuff, will update if these end up releasing**

## Adding custom content:

There are specific guides for each type of item that you can add in: [Adding custom content](customContentGuide.md)

Each type of content has a video, but if you want to test something quickly you can always replace an existing file of the same type. Keep in mind this is only useful for quick tests, since replacing old content is obviously not recommended the proper way to share your custom content is providing the necessary info explained in the respective video.
