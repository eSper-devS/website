# 3D Model files / SCNs

S4 League uses a proprietary format for all the 3d models, any file that has the .scn format either contains a straight up model or assets(animations) for the armature of the characters.

For this your best bet right now is @aeven.dev 's tool:
https://github.com/Aeven-Dev/UnityScnTool
It does allow importing .scn files and exporting models as non-proprietary formats, it does allow you to export stuff as .scn for creating custom content

You need unity to use it, installation instructions are in the github page:
https://github.com/Aeven-Dev/UnityScnTool/wiki/Instalation!-:D

How to use instructions:
https://github.com/Aeven-Dev/UnityScnTool/wiki/How-to-use!--%E2%9D%A4%EF%B8%8F
